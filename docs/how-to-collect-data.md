# 如何把探针数据回传给我

> 结论先说：**AstroBox 2.2.0 没有日志面板、没有截图、没有文件导出**（我核对了它的导航栏：探索 / 资源 / 音频同步 / 插件 / 队列 / 设置，以及它自己的运行日志——只记录蓝牙、安装、账号，不转发快应用的 `console.log`）。
> 所以探针的输出只能靠"看屏幕"。下面按从快到稳给三条路。

---

## 路线 0：最小回传集（6 条，现在就能发）

不用装新包，打开已装的「输入探针」，只看这 6 件事，**用文字回我就行**：

| # | 看什么 | 在哪看 |
|---|---|---|
| 1 | `typeof gyro=` 后面是 `function` 还是 `undefined` | 一进应用的第一屏日志 |
| 2 | 点「陀螺仪」后，有没有出现 `GYRO x=…`；有没有 `GYRO fail code=…` | 日志区 |
| 3 | 点「加速度」后，是出现 `accel #1 x=…`，还是 `accel fail code=…` | 日志区 |
| 4 | 点「罗盘」后，有没有 `compass #1 dir=… acc=…` | 日志区 |
| 5 | **只转表冠**（不碰屏幕），有没有 `SCROLL(no touch) dy=…` | 日志区 |
| 6 | 按表冠 / 返回键，有没有 `*** onBackPress 触发`，页面是否退出 | 日志区 + 页面 |

这 6 条就能判定：陀螺仪有没有、加速度开没开、罗盘通不通、表冠能不能滚、返回键能不能拦。

---

## 路线 A：装 v1.1，**拍一张照片**回传（推荐）

旧的日志区只有 9px 字、一屏 6~7 行，拍照容易糊。v1.1 加了一个「一键全测 + 汇总页」，把结果压成 12 行大字。

**1. 装包**

把 `<local-path>` 拖进 AstroBox 窗口（**不要点"安装快应用"按钮**，那个原生文件框会死锁）。

- 包名没变（`com.probe.rw6input`），版本 1.0.0 → 1.1.0，正常是覆盖升级。
- 若提示已存在/安装失败：先在 AstroBox 的设备页把「输入探针」卸载，再拖一次。

**2. 跑一遍**

打开「输入探针 v1.1」：

1. 先**只转表冠**滚几下（滚 5~10 格），让它记下 `CROWN` 数据；
2. 再按一次返回键（触发 `BACK`）；
3. 点绿色的 **「一键全测」**；
4. 等 **10.5 秒**，它会自动跳到「结果汇总」页；
5. **拍这一屏**发我。

> 汇总页点屏幕任意位置会返回主页面；想看最新数据就再按一次「汇总」。

**3. 12 行的含义**

| 行 | 含义 | 我能判定的东西 |
|---|---|---|
| `1 DEV` | 机型 + APILevel | 确认是不是 RW6、固件 API 级别 |
| `2 GYRO` | `NOFN`=方法不存在 / `NONE`=有方法但无数据 / `OK{n}`=有数据 / `FAIL{code}` | 陀螺仪到底有没有 |
| `3 ACC` | 同上 | 加速度计在 RW6 上是否真的被关掉（推翻或确认官方支持表） |
| `4 COMP` | 同上 | 罗盘可用性与采样数 |
| `5 LIGHT` | 同上 | 未文档化的环境光接口是否真的在跑 |
| `6 STEP` | `FAIL203` 之类 | 计步是不是恒失败桩 |
| `7 HLTH` | `K{n}`=模块有 n 个方法 / `EMPTY` / `NO` | `@service.health` 是否存在、方法数 |
| `8 VIB` | `OK/S0`=vibrate 可用但 start 不存在 | 振动档位 |
| `9 CROWN` | `t{次数} d{累计位移}` | 表冠能否驱动滚动、方向与幅度 |
| `10 BACK` | `Y{次数}` / `N` | 返回键能否被应用接住 |
| `11 CAN` | `s1v1e1` = sensor/vibrator/event 的 canIUse 结果 | feature 白名单实际状态 |
| `12 DTYPE` | `n{个数}` | 运行时传感器类型表大小 |

**4. 兜底：只抄最后一行**

如果照片里 12 行有糊的，底部还有一行：

```
CODE gyro|acc|comp|light|step|health|vib|crown|back
```

把这行 `CODE` 后面的内容打给我，我就能还原 9 项结论。例：`CODE NOFN|FAIL201|OK38|NONE|FAIL203|K4|OK/S0|7|1`

## 路线 B：不装新包，逐项拍照

如果不想重装，也可以就用 v1.0：

1. 点「清空」；
2. 只点**一个**按钮（比如「陀螺仪」），等 2 秒；
3. 手机靠近屏幕拍日志区（9px 字，尽量放大、别开广角）；
4. 逐个功能重复：陀螺仪 → 加速度 → 罗盘 → 环境光 → health → 振动；
5. 表冠和返回键要单独拍，因为它们不靠按钮触发。

一共 7 张左右，比路线 A 麻烦，但不用重装。

## 三个坑，提前说

1. **「一键全测」不包含表冠和返回键**——这两个必须你在跑测试前手动做一次，否则 `CROWN t0`、`BACK N` 是正常的，不代表不可用。
2. **汇总页会卸载主页面**，所以进汇总页之后再滚表冠不会计数。要更新数据：点屏幕回到主页 → 滚表冠 → 再点「汇总」。
3. **debug 签名**：这个 rpk 用的是 toolkit 自带证书。如果手表拒装，需要你自己的 `sign/private.pem` 走 `npm run release` 重打——先试拖拽，装不上再说。
